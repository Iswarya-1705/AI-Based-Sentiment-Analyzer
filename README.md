# AI-Based-Sentiment-Analyzer
Project Title: AI-Based Sentiment Analyzer

Description:

This project is part of my Python Developer internship at Codec Technologies, where I learned how to build and deploy a sentiment analysis web application using Flask and TensorFlow. The app performs sentiment analysis on user-provided text and classifies it as positive, negative, or neutral. It leverages pre-trained models from TensorFlow’s Keras library, specifically MobileNetV2, to analyze text sentiment.

Key Features:

Real-time sentiment analysis of user input text.
Web interface built with Flask.
Backend powered by TensorFlow for sentiment classification.
Simple and interactive design for ease of use.

Technologies Used:

Python (Flask, TensorFlow, Keras)
Frontend: HTML, CSS, JavaScript
Tools: VS Code, Git, GitHub

Feel free to explore the code and try the application locally. This project showcases my skills in backend development, AI, and web deployment.
